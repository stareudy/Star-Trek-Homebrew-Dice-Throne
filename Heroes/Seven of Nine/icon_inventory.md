# Seven of Nine icon inventory

Scope: hero board abilities and hero-specific cards, using `rules.txt` only. Leaflets and Shared assets are deferred until the icon conversion work in the other chat is complete. No image, SVG, PDF, or other artwork asset was inspected for this revision.

**CP tags are not considered icons and are excluded.** Entire card `Cost:` lines are excluded. CP symbols used inside actual rules remain included, because those are gameplay icons rather than CP tags.

This inventory records required icon references from the rules. Icon format is omitted while the assets transition to vectors. Icon sizing is governed by the style guide for each asset type and is not tracked here. Number-text editability in saved artwork has not been inspected.

Number values below come from explicit numbered markup such as `{{normal_damage.svg}4}`. “None” means the reference has no overlaid number in the rules. Quantities outside the markup, such as `3 {coffee_token.svg}`, do not turn that token into a numbered icon. Counts are occurrences of icon markup, not quantities of dice rolled, tokens gained, or damage dealt. Plain prose does not imply an extra icon.
