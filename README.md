# Star-Trek-Homebrew-Dice-Throne

This repository will hold all fall files required for my project to create a Star Trek Voyager themed expansion to the popular game Dice Throne 

The scope of this project will be to create four playable dice throne heroes based on characters from Star Trek Voyager. and then to create a playable cooperative expansion based on the starship Voyager culminating with a fight against the Borg Queen
