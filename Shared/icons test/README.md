# Icon vectorization test drafts

These are draft SVG redraws of the source PNG icons. Each file contains vector paths; no source PNG is embedded. The appearance is generated by palette-reduced contour tracing, so these are review drafts and may need hand cleanup. Textured token art uses a smaller palette and gentle smoothing to reduce fine raster texture.

## Organization

- `Shared/`: Shared icon drafts. The six numbered badge families each have one editable-number template based on their `_none.png` source.
- Numbered CP tags are omitted because they are already available as vector art.
- `Heroes/Janeway/`, `Heroes/Tuvok/`, and `Heroes/Future Heroes/.../`: Hero-specific drafts, grouped by source hero.
- Every numbered die face has a separate SVG with an editable text number and a matching `_no_number.svg` draft. Each face retains its own distinct illustration.

Each SVG includes the source-relative path in its description. Source PNGs were not changed.
